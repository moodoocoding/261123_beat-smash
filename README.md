# 비트스매시 클럽

2026 충북 AI 페스티벌 체험 부스용 웹앱입니다. 초등학생이 만든 4레인 리듬 게임에 이름 입력과 오늘의 랭킹을 더했습니다.

- `index.html`: 랭킹을 더한 앱
  - 시작할 때 이름 입력, 게임이 끝나면 내 등수와 TOP 5, 🏆 랭킹 버튼
  - 한글 입력 상태에서도 D · F · J · K 키가 듣도록 수정
  - 화면 주사율이 높은 모니터에서도 노트가 같은 빠르기로 떨어지도록 수정
  - 배경음악 추가: AI(Claude)가 작곡한 곡을 음악 파일 없이 Tone.js 신시사이저가 바로 연주 (이지 100 · 클럽 124 · 하이퍼 150 BPM)
  - 노트가 멜로디 음에 맞춰 떨어지도록 수정 (판정선에 닿는 순간이 그 음이 나는 순간)
- `board.js`: 부스 공용 랭킹 (다른 부스 앱과 같은 파일, Firebase `beat` 컬렉션 사용)
- `원본_학생작품.html`: 학생이 만든 원본
